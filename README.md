# PNP Global Payment - Exchange Rates Platform

Fast, Secure & Trusted Money Transfers Across Africa

## Project Structure

```
├── frontend/          # React/Next.js frontend
├── backend/           # Node.js/Express API
├── docker-compose.yml # Docker configuration
└── README.md
```

## Features

✅ Real-time Exchange Rates (Dollar to Naira)
✅ Fast & Secure Transactions
✅ Africa-Wide Transfers
✅ Competitive Rates Display
✅ 24/7 Customer Support
✅ Business Payment Solutions
✅ Cross-Border Payments

## Getting Started

### Backend Setup
```bash
cd backend
npm install
npm start
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```

## API Endpoints

- `GET /api/rates` - Get current exchange rates
- `POST /api/convert` - Convert currency amounts
- `GET /api/rates/history` - Get rate history
- `POST /api/transactions` - Create transaction
